# Overview

Both platforms are enterprise-grade cloud services for building generative AI applications and agents at production scale, but they take different approaches. **Note on naming:** Microsoft has renamed "Azure AI Foundry" to **"Microsoft Foundry"** as of 2026 documentation ([Microsoft Learn](https://learn.microsoft.com/en-us/azure/foundry/what-is-foundry)); this report uses "Azure AI Foundry / Microsoft Foundry" interchangeably since that is the terminology users will encounter in older material.

> **Sourcing note:** Official docs ([Microsoft Learn](https://learn.microsoft.com/en-us/azure/foundry/what-is-foundry), [AWS Bedrock](https://aws.amazon.com/bedrock/), [AWS Bedrock Pricing](https://aws.amazon.com/bedrock/pricing/)) were used for core facts. Comparative figures (cost percentages, model counts in some cases) come from third-party industry blogs, not the vendors themselves — these are flagged as such and should be treated as estimates, not verified facts.
