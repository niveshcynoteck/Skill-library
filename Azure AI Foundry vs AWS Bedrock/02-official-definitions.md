# What Each Platform Is (Official Definitions)

| | Azure AI Foundry (Microsoft Foundry) | AWS Bedrock |
|---|---|---|
| **Official description** | A platform that "unifies agents, models, and tools under a single management grouping with built-in enterprise-readiness capabilities including tracing, monitoring, evaluations" ([Microsoft Learn](https://learn.microsoft.com/en-us/azure/foundry/what-is-foundry)) | "The platform for building generative AI applications and agents at production scale" ([AWS](https://aws.amazon.com/bedrock/)) |
| **Resource model** | Single unified Azure resource (Foundry resource) combining what used to be separate hub/Azure OpenAI/Azure AI Services resources | Fully managed serverless service accessed via API, integrated with the AWS resource/IAM model |
