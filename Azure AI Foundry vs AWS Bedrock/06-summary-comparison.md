# Summary Comparison Table

| Dimension | Azure AI Foundry | AWS Bedrock |
|---|---|---|
| Model count | 1,900+ (official, includes broad multi-vendor catalog) | Smaller curated catalog (third-party estimates: ~30–100+) |
| Agent platform | Foundry Agent Service (prompt + hosted agents) | Bedrock AgentCore (runtime, gateway, memory, identity, policy) |
| RAG/Knowledge | Built-in memory + retrieval tools | Bedrock Knowledge Bases (managed RAG over S3) |
| Safety | Content filters, Entra ID, RBAC, network isolation | Guardrails (6 safety policies incl. automated reasoning) |
| Pricing transparency | Fragmented — per-service pricing pages | Unified official pricing page with 4 clearly defined tiers |
| Best-fit ecosystem | Microsoft/Azure-centric enterprises | AWS-centric enterprises |
