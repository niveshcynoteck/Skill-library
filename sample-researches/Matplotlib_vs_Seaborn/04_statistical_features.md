# Built-in Statistical Features

This is Seaborn's signature strength. It automatically performs **statistical estimation** — regression fitting, kernel density estimation (KDE), and **bootstrapped confidence intervals** — and supports rich distributional (histograms, KDE, ECDF) and categorical plotting at multiple levels of granularity [(Seaborn Introduction)](https://seaborn.pydata.org/tutorial/introduction.html).

Matplotlib has no such statistics layer built in — you compute regressions, densities, or intervals yourself (e.g., with NumPy/SciPy) before plotting.
