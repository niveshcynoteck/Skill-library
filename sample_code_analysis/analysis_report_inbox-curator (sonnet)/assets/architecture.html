2. Token Refresh Sequence (runs every 50 min + once at startup)

sequenceDiagram
  participant Celery as Celery Beat
  participant TR as TokenRefresh
  participant Disk as tokens.pkl
  participant AAD as Azure AD
  participant EF as EmailFetch
  participant DH as DeleteHandler

  Celery->>TR: task()
  TR->>Disk: get_tokens() [pickle.load]
  TR->>AAD: POST refresh_token grant
  AAD-->>TR: access_token, refresh_token
  TR->>Disk: save_tokens() [pickle.dump]
  TR->>EF: update(access_token)
  TR->>DH: update(access_token)

3. Daily Email Processing Sequence

sequenceDiagram
  participant Celery as Celery Beat
  participant EC as EmailCurator
  participant EF as EmailFetch
  participant Graph as MS Graph API
  participant Redis
  participant FilterAPI
  participant Chain as DeleteHandler->BounceHandler->GroupHandler

  Celery->>EC: task()
  EC->>EF: task()
  loop while @odata.nextLink
    EF->>Graph: GET messages (paginated)
    Graph-->>EF: page of emails
    EF->>Redis: rpush email JSON
  end
  EC->>FilterAPI: fetch_filters()
  FilterAPI-->>EC: groups/keywords/delete-list context
  loop until all emails processed
    EC->>Redis: lrange 0..99 + ltrim
    Redis-->>EC: batch of up to 100 emails
    EC->>Chain: handle(batch, context)
    Chain->>Graph: DELETE matched senders
    Chain->>Chain: identify bounces, extract original sender
    Chain->>Chain: POST bounced batch
    Chain->>Chain: assign groups by keyword
    Chain->>Chain: POST grouped batch
  end
