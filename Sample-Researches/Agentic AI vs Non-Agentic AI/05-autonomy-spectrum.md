# The Autonomy Spectrum

Rather than a strict binary, most current sources describe agentic capability as a **spectrum of autonomy levels**, echoing the SAE self-driving car scale. One example framework (from [agentic.ai](https://agentic.ai/what-is-agentic-ai), an industry source, not an academic standard):

| Level | Name | Characteristics | Example |
|---|---|---|---|
| L0 | Reactive Tool | Responds to prompts, takes no action | A Q&A chatbot |
| L1 | Guided Assistant | Executes assigned tasks step-by-step in a narrow domain | Coding copilot editing one file on request |
| L2 | Adaptive Collaborator | Proposes/executes multi-step plans with human approval | Research agent running an approved plan |
| L3 | Domain Specialist | Handles domain workflows independently, replans dynamically | Coding agent shipping a PR end-to-end |
| L4 | Autonomous Operator | Manages cross-domain workflows with self-correction | Sales agent running unsupervised outbound campaigns |
| L5 | Strategic Agent | Fully self-directed, sets its own goals | Long-running agent defining its own sub-goals |

L0 is effectively non-agentic; L1–L2 are "AI-assisted" but human-gated; L3+ is where most vendors apply the "agentic AI" label in practice.
