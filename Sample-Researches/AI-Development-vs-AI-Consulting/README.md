# AI Development vs AI Consulting

A comparison of two career paths and business models: **AI development** (building working AI systems) versus **AI consulting** (advising on strategy, direction, and governance).

Research conducted and compiled on **11 August 2026**. All references were validated; see `validated_links.csv`.

## File structure

| File | Contents |
|------|----------|
| `01-Executive-Summary.md` | Quick overview and the core distinction |
| `02-Definitions-and-Scope.md` | What each path involves, deliverables, engagement shape |
| `03-Business-Models-and-Revenue.md` | How each makes money, rates, margins, valuations, earnings |
| `04-Skills-and-Expertise.md` | Skills required for each path and typical routes in |
| `05-Day-to-Day-Work-and-Career-Paths.md` | What practitioners actually do day to day; career ladders |
| `06-Pros-Cons-and-Risks.md` | Advantages, disadvantages, and structural risks |
| `07-Market-Trends-and-Demand.md` | 2026 job-market data and the hybrid trend |
| `08-How-to-Choose-and-Examples.md` | Decision guidance, visuals, real-world examples, common mistakes |
| `09-Conclusion.md` | When each path is most suitable |
| `10-References.md` | Full bibliography with validated links |
| `validated_links.csv` | Link validation report (Name, Information, URL, Valid) |
| `assets/` | Visual aids: `comparison.png`, `decision_flowchart.png` |
| `scripts/` | `validate_links.sh` used for link validation |
