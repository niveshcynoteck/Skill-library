# Overview & Background

**Matplotlib** is the foundational Python plotting library — a comprehensive tool for creating static, animated, and interactive visualizations [(Matplotlib Docs)](https://matplotlib.org/stable/index.html). It's been the bedrock of Python data visualization for nearly two decades and is used by nearly every other Python plotting library under the hood.

**Seaborn** is a Python data visualization library **built on top of matplotlib**. As the official docs state directly: *"Seaborn is a Python data visualization library based on matplotlib. It provides a high-level interface for drawing attractive and informative statistical graphics"* [(Seaborn Docs)](https://seaborn.pydata.org/). It is maintained by Michael Waskom [(Seaborn GitHub)](https://github.com/mwaskom/seaborn).

**Key fact:** These are not competing alternatives — Seaborn literally cannot exist without matplotlib. Every seaborn plot is ultimately rendered by matplotlib underneath.
