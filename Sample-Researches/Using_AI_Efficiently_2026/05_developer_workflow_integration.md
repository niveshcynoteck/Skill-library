# Integration into Developer & Business Workflows

- **84%** of developers use or plan to use AI tools; **51%** use them daily.
- AI is now embedded across the full lifecycle — editors, CI/CD, documentation — not just code completion.
- **45%** of large enterprises have integrated AI code generation into CI/CD pipelines, though most *value* is still captured upstream (fast iteration in the editor) rather than deep in the pipeline.
- **Average time saved**: ~3.6 hours/week per developer.
- **A notable reversal**: developers now spend **more time reviewing AI-generated code (11.4 hrs/week) than writing new code (9.8 hrs/week)** — a flip from the 2024 pattern.
- **Trust gap**: 84% use AI tools, but only **29% trust the output** (down from 40% in 2024) — underscoring that verification remains essential.
- **Tool landscape**: Claude Code (28%) and Cursor (24%) account for over half of primary tool choices, but most developers run a multi-tool stack rather than one tool.
