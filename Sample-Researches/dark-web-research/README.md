## Summary

The dark web is a small, encrypted portion of the deep web accessible only via special networks (chiefly Tor, I2P, and Freenet), each with distinct routing architectures. It has both legitimate uses (whistleblowing, censorship-resistant journalism, activism) and significant illicit uses (marketplaces, stolen data, cybercrime). Merely accessing it is legal in most countries, but experts advise limiting engagement to specific, verified legitimate purposes rather than open-ended exploration, and to take strict precautions (dedicated device, VPN+Tor, no personal accounts). Law enforcement has repeatedly dismantled major marketplaces (Silk Road, AlphaBay, Hansa, Dream Market), pushing the ecosystem toward a more fragmented, harder-to-dismantle structure.
