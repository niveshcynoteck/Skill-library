# Access & Tools

The standard way in is the official **Tor Browser**, downloaded only from torproject.org.

## Common Recommended Precautions

- **Tor-over-VPN**: routes traffic through a VPN before Tor, hiding from your ISP the fact that you're using Tor at all.
- Keep the browser updated for security patches.
- Tor Browser has three built-in security levels — *Standard*, *Safer*, *Safest* — which progressively disable higher-risk browser features (JavaScript, media, etc.).
- Use dedicated security tools (endpoint protection, DNS filtering).
