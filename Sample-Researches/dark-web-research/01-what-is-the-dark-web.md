# What Is the Dark Web?

The internet can be understood in three broad layers:

| Layer | Description | Approx. Size |
|---|---|---|
| **Surface Web** | Public, search-engine-indexed content (news sites, blogs, stores) | ~10% of the internet |
| **Deep Web** | Content not indexed by search engines — banking portals, internal company systems, private databases, anything behind a login/paywall | ~90% of the internet |
| **Dark Web** | An encrypted subset of the Deep Web, only accessible via special software, that hides both the identity of users and the location of servers | ~6% of the internet |

A simple mnemonic: surface web is **public**, deep web is **private**, dark web is **secret**. The dark web is *not* a separate internet — it's a small, deliberately hidden portion of the deep web.
