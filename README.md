# Skill Library

A curated collection of AI agent skills and research reports for use with Claude and compatible AI assistants.

---

## Skills

### `.agents/skills/` — Agent Skills

| Skill | Description |
|-------|-------------|
| **roll-dice** | Generate random dice rolls (d6, d20, etc.) via shell commands. |
| **study-helper** | Explain complex topics as a friendly conversation between two learners. Uses simple language, analogies, and follow-up questions. |
| **summarizer** | Summarize text, documents, articles, reports, emails, meeting notes, and other written material. Produces bullet-point summaries with TL;DR. |

### `.claude/skills/` — Claude Skills

| Skill | Description |
|-------|-------------|
| **image-maker** | Create visual representations of data — Mermaid diagrams, charts (bar, pie, line), sequence diagrams, and architecture diagrams. |
| **research** | Produce structured, fact-based research reports. Supports research planning, multi-source verification, link validation, and saving output as organized Markdown files. |
